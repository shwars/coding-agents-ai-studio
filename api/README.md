# Подключение по API-ключу

> ## ⚠️ Это очень дорого, и так делать не надо
>
> При работе по API-ключу оплата списывается **за каждый токен** по тарифам Yandex AI
> Studio. Кодинг-агент за сессию прогоняет миллионы токенов контекста, поэтому счёт
> растёт очень быстро и легко превышает стоимость подписки в разы.
>
> **Для постоянной работы используйте подписку «Алиса AI Про»** — см.
> [../subscription/](../subscription/). Вариант с API-ключом берите только для
> кратких экспериментов, разовой автоматизации или отладки интеграций.

Материалы в этой папке описывают подключение OpenCode и Codex CLI к Yandex AI Studio
через статический API-ключ сервисного аккаунта.

| Документ | О чём | Готовый конфиг |
|---|---|---|
| [OpenCode](opencode.md) | Провайдер `@ai-sdk/openai-compatible` с API-ключом | [`opencode/config.json`](opencode/config.json) |
| [Codex CLI](codex.md) | Профиль Codex с API-ключом и каталогом моделей | [`codex/yandex-ai-studio.config.toml`](codex/yandex-ai-studio.config.toml), [`codex/yandex-ai-studio-catalog.json`](codex/yandex-ai-studio-catalog.json) |

YCodex по API-ключу не подключается — он работает только по подписке
([../subscription/ycodex.md](../subscription/ycodex.md)).

## Общий порядок

1. Создайте **API-ключ** в Yandex AI Studio
2. Запомните **идентификатор каталога** (`folder-id`), в котором будете работать.
3. Задайте `api_key` и `folder_id` в соответствующих переменных окружения
4. Скопируйте конфиг своему агенту (см. отдельные инструкции) и внесите в него необходимые изменения (для Codex, замените где необходимо <folder_id> на реальное значение идентификатора каталога, поскольку не всегда возможно автоматически подставить соответствующее значение из переменной окружения)

## Переменные окружения

В примерах config-файлов используются две переменные:

| Переменная | Значение |
|---|---|
| `api_key` | Секрет API-ключа сервисного аккаунта |
| `folder_id` | Идентификатор каталога Yandex Cloud (для OpenCode) |

Задайте их в оболочке:

```bash
export api_key="<API-ключ>"
export folder_id="<folder-id>"
```

## Чем отличается от подписки

| | Подписка | API-ключ |
|---|---|---|
| Аутентификация | IAM-токен (`yc iam create-token`) | Статический API-ключ сервисного аккаунта |
| Base URL | `https://apps.ai.api.cloud.yandex.net/v1` | `https://ai.api.cloud.yandex.net/v1` |
| Оплата | Фиксированная, по предоплате | За каждый токен по тарифам AI Studio |
| Срок жизни секрета | До 24 часов | Не ограничен сроком (до отзыва) |
| Когда использовать | Постоянная работа | Эксперименты и короткие демо |
